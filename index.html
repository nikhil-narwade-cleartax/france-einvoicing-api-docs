Overview

France E-Invoicing API

ClearTax is a certified Plateforme Agreee (PA) for the French e-invoicing mandate. This documentation covers the API contract for sending e-invoices through the ClearTax platform.

What this API does

The Send e-Invoice API allows you to submit invoices, credit notes, and corrective invoices from your ERP to ClearTax. ClearTax then:

  • Validates the invoice against French regulatory rules (XSD, Schematron, business rules)
  • Delivers the invoice (F2) to the buyer's platform via Peppol
  • Reports the lifecycle status (F6) to the PPF (government data hub)
  • Files the tax data extract (F1) with the PPF

Supported document types

Type CodeDocumentDescription
380Commercial InvoiceStandard B2B invoice
381Credit NotePartial or full reversal of an invoice
384Corrective InvoiceCancels and replaces a previous invoice
386Prepayment InvoiceAdvance payment invoice

Mandate timeline

PhaseDateScope
Phase 11 September 2026All businesses must receive. Large + mid-size must issue.
Phase 21 September 2027SMEs and micro-enterprises must also issue.
Penalty Non-compliance carries a penalty of EUR 50 per invoice, capped at EUR 15,000 per year.

Send Flow > Send e-Invoice

Send e-Invoice

POST /einvoice/v1/documents/send

Submit an invoice, credit note, or corrective invoice to ClearTax for validation, PPF filing, and delivery to the buyer's platform via Peppol.

How it works

  1. Build the invoice JSON payload using the PINT field paths (see Field Reference)
  2. Base64-encode the JSON payload
  3. Wrap it in the request body: {"documents": [{"documentData": "<base64>"}]}
  4. Send the POST request with required headers
  5. ClearTax validates, files with PPF, and delivers to the buyer's platform
Important The invoice payload must be Base64-encoded and placed inside the documentData field. Do not send raw JSON directly.

<\!-- REQUEST BODY -->
Send Flow > Request Body Structure

Request Body Structure

The request body contains an array of documents. Each document's data is a Base64-encoded JSON string.

JSON
{ "documents": [ { "documentData": "<Base64-encoded invoice JSON>" } ] }

Encoding steps

  1. Build the invoice JSON using the field paths from the Field Reference section
  2. Stringify the JSON object
  3. Base64-encode the string
  4. Place the encoded string as the value of documentData

Top-level invoice JSON fields

FieldTypeDescription
supplyTypestringTransaction type: B2B, B2C, B2BINT
idstringInvoice number (BT-1)
issueDatedateInvoice date (BT-2). Format: YYYY-MM-DD
