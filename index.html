France E-Invoicing API

ClearTax is a certified Plateforme Agréée (PA) for the French e-invoicing mandate. This documentation covers the Send API for submitting invoices from your ERP to ClearTax.

Mandate deadline: 1 September 2026All large and mid-size businesses must issue e-invoices. Non-compliance: €50 per invoice, €15,000/year cap.

Quick Start

Send your first invoice in 5 steps.

Get your auth token
Contact your ClearTax account manager for sandbox credentials.
Build the invoice JSON
Use the field paths from the Request Schema. At minimum: id, issueDate, invoiceTypeCode, documentCurrencyCode, accountingSupplierParty, accountingCustomerParty, taxTotal, legalMonetaryTotal, invoiceLine.
Base64-encode the JSON
echo -n '{"id":"INV-001",...}' | base64
Send the request
cURL
curl -X POST 'https://{{base_url}}/einvoice/v1/documents/send' \
  -H 'x-cleartax-auth-token: {{token}}' \
  -H 'x-clear-country-code: FR' \
  -H 'x-einvoice-type: SALES' \
  -H 'x-clear-siren: 732829320' \
  -H 'x-clear-siret: {{siret}}' \
  -H 'Content-Type: application/json' \
  -d '{"documents":[{"documentData":"<base64-string>"}]}'
Check the response
A 200 means your invoice was accepted for processing. ClearTax validates, files with PPF, and delivers to the buyer via Peppol.

Send e-Invoice

POST/einvoice/v1/documents/send

Submit one or more invoice documents for validation and routing. ClearTax validates, transforms to UBL, files with PPF, and delivers via Peppol. Supports up to 10 documents per request.

The request body wraps one or more documents. The invoice data is Base64-encoded JSON inside documentData.
