Documentation / Overview

France E-Invoicing API

ClearTax is a certified Plateforme Agréée (PA) for the French e-invoicing mandate. This documentation covers the API contract for sending e-invoices through ClearTax.

What this API does

The Send API allows you to submit invoices, credit notes, and corrective invoices from your ERP. ClearTax then:

  • Validates against French regulatory rules
  • Delivers the invoice (F2) to the buyer via Peppol
  • Reports the lifecycle status (F6) to PPF
  • Files the tax data extract (F1) with PPF

Supported document types

TypeDocumentDescription
380InvoiceStandard B2B invoice
381Credit NotePartial or full reversal
384Corrective InvoiceCancels and replaces
386Prepayment InvoiceAdvance payment

Mandate timeline

PhaseDateScope
Phase 11 Sep 2026All receive. Large + mid-size issue.
Phase 21 Sep 2027SMEs + micro issue.
PenaltyEUR 50 per invoice, EUR 15,000/year cap.

Send e-Invoice

POST/einvoice/v1/documents/send

Submit an invoice, credit note, or corrective to ClearTax for validation, PPF filing, and Peppol delivery.

Request Headers

HeaderRequiredValueDescription
Content-TypeREQUIREDapplication/jsonContent type
x-cleartax-auth-tokenREQUIREDYour tokenAuth token
x-clear-country-codeREQUIREDFRCountry code
x-einvoice-typeREQUIREDSALESOutbound invoices
x-clear-sirenREQUIRED9-digit SIRENSeller SIREN
x-clear-siretREQUIRED14-digit SIRETSeller SIRET

Request Body

The invoice data is Base64-encoded JSON inside the documentData field.

JSON
{
  "documents": [
    {
      "documentData": "<Base64-encoded invoice JSON>"
    }
  ]
}
Build the invoice JSON using field paths from the Field Reference
Stringify the JSON object
Base64-encode the string
Place it as the value of documentData
POST with required headers
